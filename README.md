# QuickClip（本地截图复制）

按下全局快捷键，拖动框选屏幕区域，松开鼠标后截图会自动复制到系统剪贴板；随后可在支持图片的富文本框中按 `⌘V` 粘贴。

## 运行

在终端中执行：

```zsh
./build-app.sh
open QuickClip.app
```

首次截图时，系统会请求“屏幕录制”权限。请允许 QuickClip；若未出现提示，可前往“系统设置 → 隐私与安全性 → 屏幕录制”手动开启。

## 使用

- 默认快捷键：`⌥⇧A`
- 按下后拖动鼠标框选；松开即复制
- 按 `Esc` 取消
- 点击菜单栏的虚线矩形图标，可手动发起截图或打开快捷键设置；设置窗口打开后直接按下组合键即可保存，不需要勾选或点击“保存”。按 `Esc` 或“取消”会保留原快捷键。
- 如果菜单栏图标被系统折叠或隐藏，可在 Finder、Spotlight 或外接硬盘中再次打开 `QuickClip.app`；后台已运行时会直接弹出快捷键设置窗口。

快捷键只能在 QuickClip 正在运行时生效。若按键无反应，先确认菜单栏中是否有虚线矩形图标；没有时请打开 QuickClip.app，并检查“系统设置 → 通用 → 登录项”是否允许其后台运行。

## 首次验收

1. 双击 `QuickClip.app`，确认菜单栏出现虚线矩形图标。
2. 按 `⌥⇧A`，授权屏幕录制后拖动选择一个区域。
3. 打开任意支持图片粘贴的富文本框，按 `⌘V`，确认图片清晰且选区正确。
4. 从菜单栏进入“快捷键设置”，换成一个不冲突的组合键后再次验证。

后续能力的优先级和取舍见 [ROADMAP.md](ROADMAP.md)。

## 说明

- 不会自动保存截图，也不会上传网络。
- 需要 macOS 14 或更高版本。
- 项目当前采用临时本地签名，系统可能在首次打开时显示来源提示。需要时可在 Finder 中右键 App，选择“打开”。
