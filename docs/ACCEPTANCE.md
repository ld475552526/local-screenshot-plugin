# QuickClip 验收方案

发布前必须先完成自动验收，再在真实 macOS 桌面完成手动验收。任何 P0 项失败都不得发布。

## 自动验收

```zsh
swift build -c release --disable-sandbox
swift test --disable-sandbox
./build-app.sh
codesign --verify --deep --strict QuickClip.app
```

全部命令必须以 `0` 退出；测试不得失败；App 必须存在且签名校验通过。

## 手动验收

| ID | 场景 | 通过标准 | 优先级 |
| --- | --- | --- | --- |
| QAC-01 | 首次授权：启动后按快捷键，点击“前往系统设置”，开启屏幕录制权限并重试。 | 系统准确打开“屏幕录制”设置；授权后截图可用。 | P0 |
| QAC-02 | 基本截图：用 `⌥⇧A` 框选含文字和图片的区域。 | 覆盖层消失，菜单栏短暂显示勾选。 | P0 |
| QAC-03 | 剪贴板：在备忘录、Slack/飞书或浏览器富文本框按 `⌘V`。 | 图片可粘贴，清晰且不包含遮罩或选框。 | P0 |
| QAC-04 | 取消：按 `Esc`、单击、拖动小于 3 px 的选区。 | 不写入新图片，之后仍能截图，App 不崩溃。 | P1 |
| QAC-05 | 快捷键：改为 `⌃⌥S`；再尝试被占用的组合键。 | 新键生效；失败时设置窗不关闭，原组合键仍可用。 | P0 |
| QAC-06 | 多屏：在两个显示器各截图一次并框选跨屏区域，至少一台 Retina。 | 图片内容、边界和清晰度正确，无崩溃。 | P0 |
| QAC-07 | 撤销权限：在系统设置关闭屏幕录制后触发截图。 | 显示权限引导、可打开设置、不会生成空白图。 | P0 |
| QAC-08 | 稳定性：连续截图 50 次，其中至少 10 次取消或调整选区。 | 无崩溃、无遮罩残留、无明显卡顿。 | P1 |
| QAC-09 | 登录项：首次启动与手动开关菜单项。 | 默认不自动添加登录项；开关与系统设置一致。 | P1 |

记录构建版本、macOS 版本、显示器数量/缩放、执行人和每项结果。修复任一问题后，必须复测失败项以及 QAC-02、QAC-03、QAC-05、QAC-07。发布准入条件：全部 P0 通过、P1 无未接受回归、自动验收通过。无外接屏时不得声称完成 QAC-06。
